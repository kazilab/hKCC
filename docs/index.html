hKCC

Key characteristics of human carcinogens

An open database linking carcinogens to the mechanisms behind them.

hKCC maps carcinogenic agents to the ten key characteristics of carcinogens — the mechanistic framework used to organise evidence in IARC Monographs. Every score is derived from a published source table, and every one links back to its citation.

Early development (v0.0.x). The dataset, schema and API are still changing between releases. Scores are derived from published source tables by documented rules, not assigned by hand — read the evidence rules before relying on a value.

What it covers. Two published sources: the IARC Monograph Volume 100 Group 1 re-review (Krewski et al. 2019) and Volumes 112–130 (Rusyn et al. 2024). Every score records which source produced it; the two use different derivation rules, set out in the evidence rules. Volumes 107–111 are covered by neither.

Three ways to use it

1 · In your browser — nothing to install

Open hu-kcc.streamlit.app and start browsing. Look up an agent to see its mechanistic fingerprint, open the evidence matrix to compare agents side by side, or search the assay library for methods that measure a given characteristic.

2 · On your own machine — pip install hkcc

The dataset ships inside the package, so there is no database to set up and nothing to download separately.

pip install hkcc

hkcc          # opens the app at localhost:8501
hkcc info     # shows the version and where the data lives

3 · From code — the JSON API

Run the read API locally and query it from any language. No key, no account.

hkcc api      # serves on localhost:8000, docs at /docs

curl http://localhost:8000/api/v1/matrix
curl http://localhost:8000/api/v1/agents

Reading the evidence scores

Each agent × characteristic pair carries a score from 0 to 4. Scores are not assigned by hand — they are computed from the IARC 10-year retrospective by a documented, deterministic rule, so any value can be traced back to a specific row of the source publication.

ScoreMeaning
4Convincing — strongest positive tier
3Substantial
2Limited — weakest positive tier
1Equivocal — mixed or inconclusive
0No positive evidence in the primary model systems
blankNot assessed — the pair was never evaluated

0 and blank are different claims. A 0 means the sources looked and reported nothing positive; a blank means nobody looked. Only 844 of the 1,710 possible pairs have been evaluated, so most of the matrix is legitimately blank. The full derivation, including how the published strength labels map onto this scale, is in the evidence rules.

Where the data comes from

Two peer-reviewed datasets. Every derived row points back to one of them.

IARC 10-year retrospective

Per-volume, per-model-system calls across Monograph Volumes 112–130, and the standardized strength labels that produce the evidence scores.

Rusyn I, Wright FA, Smith MT, et al. Ten years of using key characteristics of human carcinogens to organize and evaluate mechanistic evidence in IARC Monographs Volumes 112–130. Toxicological Sciences 198(1):141–154 (2024). doi:10.1093/toxsci/kfad134

KCAD — Key Characteristics Assay Database

The assay library, study-level annotations, abbreviation glossary and column dictionary.

Rigutto G, McHale CM, Singam ERA, Rana I, Zhang L, Smith MT. Mapping assays to the key characteristics of carcinogens to support decision-making. Database (Oxford) 2025, article baaf026. doi:10.1093/database/baaf026

Citing hKCC

The dataset is released under CC-BY-4.0 and the code under MIT. BibTeX and RIS records are served by the API at /api/v1/agents/citation/resource.bib and .ris.

hKCC is not a classification authority. IARC group assignments are reproduced from the monographs; the mechanistic scores are hKCC's derivation from the published tables.
